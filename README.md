# 实验室离心转子配平（rotor-balance）

录入转子参数、本次全部离心管（编号 / 称重质量 / 可用孔位）与可选配重块（质量 / 数量），
系统自动求解满足对径差约束的装载图，并支持草稿重算、原子复核发布与历史装载图冻结。

技术栈：Node.js 20+ · Express · SQLite（better-sqlite3）· 原生 HTML/JS 前端（无构建步骤）。

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

启动后访问：**http://localhost:3000**

首次启动自动完成依赖安装（`npm ci`）与数据库初始化（建表，无需手动迁移）。
SQLite 数据文件保存在命名卷 `rotor-data` 中，容器重建不丢数据。

也可以只用 Docker：

```bash
docker build -t rotor-balance .
docker run -d -p 3000:3000 -v rotor-data:/app/data rotor-balance
```

## 配置项（环境变量）

| 变量      | 默认值              | 说明                     |
| --------- | ------------------- | ------------------------ |
| `PORT`    | `3000`              | 容器内 HTTP 监听端口     |
| `DB_PATH` | `/app/data/app.db`  | SQLite 数据库文件路径    |

对外端口在 `docker-compose.yml` 的 `ports` 中修改（如 `"8080:3000"`）。

## 本地运行（不用 Docker）

要求 Node.js ≥ 20：

```bash
npm ci
npm start          # http://localhost:3000
npm test           # 求解器单元测试 + 暴力交叉验证
```

本地默认数据库路径为 `./data/app.db`（可用 `DB_PATH` 覆盖）。

## 使用流程

1. **转子参数**：孔位数（偶数 4–12）、单孔最大质量 (g)、允许对径差 (g)。
2. **离心管**：录入本次全部离心管的编号、称重质量、可用孔位（逗号分隔）。
3. **配重块**（可选）：编号、单枚质量、数量；每枚最多使用一次。
4. **求解装载图**：得到可行装载图（含每孔物件、各对径孔差值）或明确的无解提示。
5. **发布装载图**：将当前草稿原子复核后冻结；历史装载图可随时查看。

## 求解规则

- 每孔最多一件物件；所有离心管必须装入；每枚配重最多用一次；空孔质量按零计。
- 每对对径孔（`i` 与 `i + 孔数/2`）的质量差不得超过允许对径差。
- 目标按优先级：
  1. **配重块使用数量最少**；
  2. **各对径差之和最小**；
  3. 同分时按孔位 1..N 的**物件编号序列**取字典序最小（空孔视为“最大”，
     即同分时物件优先占据小编号孔位；同质量配重优先使用小编号）。
- 不存在可行方案时明确提示无解及原因。

## 草稿、发布与数据版本

- 转子 / 离心管 / 配重的任何变更都会使内部**数据版本** +1。
- 草稿记录其计算时的数据版本；数据变更后旧草稿标记为**需重算**，重新求解前不能发布。
- **发布**在单个事务中完成原子复核：版本一致 → 逐条重验装载约束 → 以当前数据重新
  求解确认草稿仍为最优 → 冻结装载图及依据（转子参数、离心管、配重快照）。
- 已发布装载图**永不修改**；此后数据一旦变更，旧图自动标记为
  **不可用于当前装载**（即使内容改回，版本已前进，标记保留）。

## 输入校验（失败即整体拒绝，不留部分数据）

- 质量必须为正数且不超过单孔最大质量；数量必须为非负整数。
- 编号不能为空且不可重复（离心管、配重各自命名空间内唯一）。
- 可用孔位必须在 1..孔数 范围内且非空；孔位数必须为 4–12 的偶数。
- 修改转子参数若会使既有离心管 / 配重变为非法（质量超上限、孔位越界），整体拒绝。
- 所有写操作包裹在 SQLite 事务中，任一校验失败即回滚。

## API 一览

| 方法 | 路径                       | 说明                                   |
| ---- | -------------------------- | -------------------------------------- |
| GET  | `/api/state`               | 全部状态（含草稿 stale、发布 usable）  |
| PUT  | `/api/rotor`               | 设置转子参数                           |
| POST | `/api/tubes`               | 新增离心管                             |
| PUT  | `/api/tubes/:id`           | 修改称重质量 / 可用孔位                |
| DELETE | `/api/tubes/:id`         | 删除离心管                             |
| POST | `/api/counterweights`      | 新增配重                               |
| PUT  | `/api/counterweights/:id`  | 修改配重质量 / 数量                    |
| DELETE | `/api/counterweights/:id`| 删除配重                               |
| POST | `/api/draft`               | 以当前数据求解，生成新草稿             |
| POST | `/api/publish`             | 原子复核并冻结当前草稿                 |
